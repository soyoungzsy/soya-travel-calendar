# Soya Travel Calendar contributor instructions

Use one modern sans-serif family and the existing magazine layout. Keep a single date and budget entry region. Keep personal destinations in browser-local storage; do not send them to reference-data services or GitHub. Document photos are transient browser-local OCR inputs only: self-host OCR assets, never upload or persist scans/raw OCR text, and save only allowlisted travel fields after explicit review. Never include real documents, identity numbers, portraits, barcodes or their OCR output in the repository, fixtures, screenshots, logs, Issues or PRs. A separately authorized private local archive must stay outside the source tree. Validate untrusted imports, preview changes, preserve backups and avoid remote HTML injection. Use branches and reviewable pull requests for subsequent changes; do not merge without authorization. Run npm run build then npm test. Respect media licenses in docs/media-credits.md. Do not label budgets as live prices, or promise visa clearance.
