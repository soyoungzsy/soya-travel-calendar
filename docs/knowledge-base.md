# 旅行知识库：来源、覆盖与更新

这是一份有来源、有核验状态的编辑资料快照。地点索引、完整度、季节与当天可用性分别处理，不以数量代替核验。

## 当前实际收录

页尾与“知识库与参考资料”从 `src/knowledge-audit.mjs` 自动计算同一份统计，不手写另一套数字：34个国家与地区、72个去重目的地（73张目的地季节灵感卡）、175条具体景点资料（176张景点/季节卡）、22条本轮逐点核对的深度景点资料、13个地区26项地方风味、4地8条行前阅读。按URL去重的内容参考资料182份，其中80份至少有一项正文核验记录；不因此将同页其他用途一并升级。其余既有摘记、搜索摘要和未重新复核的来源保留状态。

3本行前图书只核过书目、简介与版本，5篇官方行前短文已读正文。不将8条阅读入口计为8本通读著作。统计不含私人地点、收藏、证件、图片署名、实时汇率及关注度请求。南极洲等作为旅行区域统计，不称主权国家数量。景点按基础资料ID计数，季节变体计一次；同名异写仍需人工合并。地点条目不等于该地点的全部知识已经收齐。

地图另有258个国家与地区入口，来自Natural Earth 1:1000万Admin0 Countries v5.1.1，源发布于2022-05-13，本轮核对于2026-10-18。底图经过显示简化，不表示此刻各地行政变化、测绘/导航精度或主权认定。地图覆盖不混入旅行内容覆盖。

## 内容与出处

- `src/poi-catalog.json`：22条本轮逐点核对的自然/人文详卡；原用途、人物事件、具体观察、分期年代、中国历史参照与世界文化意义分别呈现。宗教叙事和史实区分；人物营建不等于曾居住；入遗年份不是建造年代。
- `src/data.mjs`、`src/discoveries.json`、`src/travel-guides.json`：既有目的地与旅行实用资料；派生摘记明确标注未逐点复核。历史攻略不能证明当前票价、营业、交通或花况。
- `src/food-catalog.json`：13地26项饮食体验，保存官方来源与独立编辑建议。成都使用官方地方志/商务部补充，九寨沟使用历史饮食报道，不冒称文旅局逐菜背书或当前商户菜单。国家/地区风味不冒称城市独有。
- `src/reading-catalog.json`：四地阅读入口、书目版本、作者/机构、原文入口与现场问题。文学不能直接充当史实；仅核出版社简介不生成假章节或读后感。当前没有声称已完整观看的纪录片。
- `src/knowledge-audit.mjs`：按来源URL聚合具体用途、地点、日期与核验状态，供页尾统计、国家表和参考文献搜索共用。来源正文被核过不等于其全部内容已审校；参考不表示机构背书。
- `src/official-sources.json`：机构与接口目录，文档核验不等于已经接通所有服务。主要参考地方文旅、旅游局、博物馆、文物机构、出版社及明确标注年代的旅行者资料。

## 什么时候值得去

文化价值、舒适季节、当年事件与当天可用性是不同字段。`year_round`全年展示文化看点，不保证每天开门；`seasonal`按月份/日期选择体验；春秋变体关联同一个基础地点；`event`按明确实际档期匹配；`conditional`如潮汐需查询指定日官方预报；`unknown`不据空白生成推荐窗口。

已提供苏堤春秋两张看点卡，秋季桂花不在春季推荐出现。中国茶博临展按2026-07-17至11-30显示；过期后常设文化卡仍保留。摄影注明历史日期或物种参考，不冒充当天花况。钱塘江不生成固定公历潮时。

## 授权与公开边界

公开阅读、API访问、全文存储、向外部AI传输、公开再分发是不同权限。代码MIT不改变照片、书籍与引用资料各自的权利。

UNESCO DataHub whc001元数据标记CC BY-SA 4.0，同时说明链接WHC syndication的另行书面授权要求；适用范围有待提供方澄清。当前 `src/knowledge-index-meta.json` 明确关闭批量导入/分发，`public/`不包含该批候选数据，浏览器不请求，单文件版本也不内嵌，页尾不计数。仅删除简介/图片不能自动解决条款差异。单个官方地点页面作为核验/延伸阅读链接分别处理；不镜像其全文。

Wikidata CC0可用于实体关联，当前未批量导入。DATAtourisme和NPS已核接口文档，尚未申请密钥或启用采集；媒体逐件核对许可。国家旅游局官网不统一适用开放许可。已有摄影仍按 `src/media.json`、`src/poi-media.json` 与图片署名逐件管理。

## 维护流程

1. 登记机构、负责领域、URL、语言、接口与许可。
2. 在允许范围定向获取，标记正文/摘要/书目/失败；未取得不解释为没有变化。
3. AI辅助写事实草稿与原创推荐，保留字段级证据、适用期与编辑假设；无依据保留缺口。
4. 校验ID、地点关联、日期、引用、统计与隐私，再编辑审核、PR审查和发布。
5. 按资料性质定向复查。历史与地域文化可低频查变更；花况、临展、开放与潮时在接近出发日复核。当前没有后台自动抓全网或自动发布任务。

`npm run knowledge:check`离线校验结构并输出与网页一致的统计，明确不声称重新访问原文。`npm run build`后执行`npm test`检查季节、书目状态、统计去重与权限关闭等逻辑。新增资料按相同字段经PR审核，失败保留原版本，不自动覆盖人工内容。

`npm run data:heritage`当前在联网/写入前停止，直到配置中记录许可已澄清与可回访的决定依据；不能只改一个license字符串就当作取得授权。`npm run data:cartography`从固定官方修订复现显示底图；更换版本要审查覆盖、表示、标签、来源与许可。

公开站点与下载包只含审查过的公共资料。私人收藏、小红书登录态、证件及原图不进入公共语料、来源统计或GitHub。切换域名不会自动迁移浏览器存储，地点清单可先导出备份。
