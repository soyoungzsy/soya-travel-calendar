# 山河有期：阿里云中国内地部署

**当前状态：独立 Node 服务与静态资源已适配并在本地验收；尚未购买服务器、完成ICP备案或切换域名。当前公开网站仍由 Sites/Cloudflare 提供服务，国内无VPN访问问题尚未宣称解决。**

域名注册商和网站托管商是两个角色。在阿里云购买 `scenicdue.com` 不会自动迁移网页，也不会取消原托管平台的安全与地区规则。

## 本次建议资源

阿里云中国内地杭州地域 ECS 经济型 e：2核2G、3Mbps固定带宽、40GB ESSD Entry系统盘、购买1年。2026-10-19查阅的[官方99计划](https://www.aliyun.com/activity/ecs/99program)报价99元/年；具体账号资格、地域库存、订单和续费条件须在结算页确认。没有获得优惠时，不自动接受日常价或增购。域名已购买，无需再买域名；暂不需要数据库、负载均衡或付费建站。

3Mbps是图片站的起步带宽，不能据此承诺并发量。首屏图片按需加载、地球影像优先、云层延后，Nginx压缩文本，图片保留缓存；有实际流量后再评估国内静态加速费用。

内地网站须先按实际主体完成ICP备案。阿里云[个人网站流程](https://help.aliyun.com/zh/icp-filing/basic-icp-service/getting-started/quick-start-for-icp-filing-for-personal-websites)给出的预计审核区间约3—22个工作日，实际以属地和补正为准。域名实名不等于ICP备案；本人核验、短信、人脸及法律条款由站长亲自处理。备案期间原网站是否需要关闭，按实际备案场景与审核要求执行，不擅自继续开站或承诺可以并行。

## 已准备的部署内容

- `server/node-server.mjs`：独立静态文件服务，复用现有只读 `/api/fx`、`/api/interest`、机酒查询状态接口，不依赖 Cloudflare 的 `env.ASSETS`。
- `dist/client/`：构建后的网页、摄影、地球和本地OCR资源。资源在新站同域提供，不能继续从旧 `chatgpt.site` 回源。
- `nginx.conf.example`：HTTPS入口与压缩。证书单独放在服务器 `/etc/nginx/tls/`，私钥不进源码。
- `scenicdue.service.example`：以独立低权限用户运行 Node，不需要Docker或运行时npm依赖。

服务器上的 Node 需要22.12或以上。生产包无需在服务器重新装前端依赖或构建；运行包内的 `node server/node-server.mjs` 即可。Node安装路径若不是 `/usr/bin/node`，相应调整服务示例。示例未在真实阿里云主机上执行，须部署时检查现有端口、服务、系统和证书路径。

## 构建与本地验收

```sh
npm ci
npm run build
npm test
node scripts/package-server.mjs
```

输出位于 `.release/server-v<版本>/`，里面包含最小运行清单和许可证。将整目录打包，复制到新服务器的版本目录；不要上传工作目录、`.git`、`.env`、私人笔记或证件照片。正式服务前先在服务器环回地址运行，验证首页、图片、WASM、深链接及只读接口。

## 域名切换的顺序

1. 核对订单实付金额、购买时长、公网带宽、地域与实际主办者信息；本人完成支付和备案核验。
2. 准备Linux运行环境，部署版本目录和独立服务，验证 `127.0.0.1:8080`；检查并保留已有服务配置，不覆盖其他网站。
3. 完成ICP备案、证书准备和HTTPS入口，在允许正式开站后再切DNS。证书通过正式域名验证流程取得，原Sites托管证书不能当作已导出的新站私钥使用。
4. 记录当前DNS以便回退。把 `scenicdue.com` 指向新服务器，检查HTTPS、静态资源和接口均没有依赖旧站；浏览器本地资料仍留在同一域名下。
5. 页尾添加实际获批备案信息，按官方要求办理后续备案事项。不要编造备案号。
6. 关闭VPN，分别用电信、联通、移动及手机网络抽样检查首次加载、地球旋转/缩放、照片、攻略、收藏、证件本地识别；有核心流程还需要VPN时，不得把迁移标为完成。

外部参考数据源可能暂不可达：前端保留带日期的既有汇率/关注度参考，绝不把失败伪装成实时数据。该降级不应阻塞地球、照片和攻略。服务器没有账号数据库或证件上传接口，收藏与证件识别继续保留在浏览器本地。
